# Step 9: Executive Communication

## Objective
Produce two coordinated deliverables: an Executive Summary and a Future Press Release. The press release depicts an H3 end state consistent with the conviction bets in the executive summary.

## Inputs
Steps 1 through 8 are available in workflow context. All factual content, named initiatives, KPIs, and timelines must trace to those outputs. The persona is a metadata field; the summary is addressed to the persona, not about them.

## Web search
Two triggers: GAP_OR_VALIDATION (an upstream output is missing/contradictory/needs triangulation), FACTUAL_ANCHORING (verify present-day baseline facts the press release projects forward). Do not use web search to regenerate foresight content.

SEARCH BUDGET (strict)
MAXIMUM of 3 times for this entire task, only under GAP_OR_VALIDATION or FACTUAL_ANCHORING. Most runs need zero or one search. Where a fact cannot be verified, use a bracketed placeholder.

## Executive Summary
600 to 900 words. Senior analyst writing to a principal. Diagnostic before prescriptive. Six sections in order: 1. STRATEGIC QUESTION, HORIZON, SCOPE. 2. BASELINE DIAGNOSIS. 3. STRATEGIC LANDSCAPE. 4. IMPLICATIONS FOR THE DECISION-MAKER (two paragraphs: stakes across alternatives incl. cost of inaction; backcast logic; hardest unavoidable choices). 5. STRATEGIC OPTIONS (No-regret moves; Hedges; Conviction bets; Things to avoid - at least one a move the org is presently inclined toward).

## Future Press Release
350 to 500 words. Newsroom-neutral voice. Open with: "FUTURE PRESS RELEASE. Speculative scenario dated [projected date]. Figures and outcomes are projections from the strategic plan in Steps 1 through 8." Then dateline (H3 window), issuing organization (verified via FACTUAL_ANCHORING), factual headline, subheadline, lead paragraph, 3-5 body paragraphs with projected metrics, 1-2 quotes attributed only to role titles or bracketed placeholders, boilerplate, contact line as bracketed placeholder. The lead describes an event/milestone that is evidence a conviction bet succeeded.

## Anti-fabrication
Named officials, partner organizations, and monetary figures not fixed in prior steps and not verifiable as present-day baselines: use bracketed placeholders. Quotes attributed to real named public figures are prohibited.

## Output Format

Return ONLY a valid JSON object:
```json
{
  "solution": { "executiveSummary": "string", "futurePressRelease": "string" },
  "solutionReferences": { "id": 9, "step": "Step 9", "referenceUrls": [], "citations": "string" }
}
```

## Rules
1. No URLs/citations in executiveSummary or futurePressRelease; collect in solutionReferences only.
2. solutionReferences: id = 9, step = "Step 9".
3. Output valid JSON with exactly `solution` and `solutionReferences` at the root.

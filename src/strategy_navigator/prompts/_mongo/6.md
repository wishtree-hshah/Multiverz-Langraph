### 3.0 EXECUTIVE BRIEF (2 pages max)

The brief must answer: (1) What are the top strategic priorities? (2) What methodology produced them? (3) What should we do in the next 30 days?

No tables. Slightly larger body text. One callout box only (the Quick Wins).

**3.0.1 Opening Paragraph (~150 words):** Core strategic question, decision context, timeframe/scope, summary of analytical process (agents, human experts, ideas generated, narrowing to top priorities). Draw from project_metadata, project_scope, ideation_process.

**3.0.2 Top 5 Strategic Priorities (~80-100 words each):** Ranked by overall_score. Each: **title (bold)** [score], 2-3 sentences of description, 1-2 sentences of strategic significance. Draw from idea description and implementation_feasibility.

**3.0.3 Methodology Note (~100 words):** Agent + human hybrid, multipool evaluation, convergence/divergence analysis. No deep technical detail.

**3.0.4 Quick Wins Callout Box:** "QUICK WIN" label. 3-5 numbered actions for the next 30 days with expected outcomes. Draw from quick_wins.

**3.0.5 Closing (~75 words):** Restate opportunity, direct to Part 2 (analysis) and Part 4 (roadmap).

### 3.1 PART 1: PROCESS AND PARTICIPATION

**3.1.1 Methodology (1-2 paragraphs):** Agentic AI + human expertise integration, multipool weighted evaluation, convergence/divergence analysis, why hybrid outperforms either alone. Draw from evaluation_methodology.

**3.1.2 Participation Overview**

Required ideation-to-evaluation flow table:
```
Foundational Agents | + | Contextual Agents | + | Human Ideators | → | Total Ideas | → | Evaluated | → | Top Priorities
```

1-2 paragraphs: what each agent type contributed (from descriptions), who the human ideators were (from categories), timeline (from ideation_timeline).

**3.1.3 Evaluation Framework**

Required table — Columns: Criterion Name, Description, Weight (%). Draw from evaluation_criteria.

1-2 paragraphs: pool composition (name, evaluator count, evaluation count per pool), total evaluations, scoring aggregation method.

**3.1.4 Quality Assurance (1 paragraph):** Divergent score review, consistency checks, outlier analysis, confidence level in rankings.

---

### 3.2 PART 2: FINDINGS AND ANALYSIS

**3.2.1 Portfolio Overview (1-2 paragraphs):** Total ideas, categories, score distribution (range, median), diversity/coverage observations.

**3.2.2 Analysis by Category**

For each category in analysis_by_category:

**Category header** with name, idea count, top score.

**Analysis (3-5 paragraphs):** From category_analysis. What opportunity does this category represent? Strategic significance? Patterns? End with: "This category encompasses [N] ideas, scores ranging from [X] to [Y], indicating [interpretation]."

**Convergence Points:** 1 paragraph intro, then for each: title (bold), 2-3 sentences with reinforcing idea IDs. Use insight callout box ("KEY FINDING") for the most significant.

**Divergence Points:** 1 paragraph intro, then for each use a tension callout box ("TENSION"): title, AI perspective (from ai_view), human perspective (from human_view), practical implication.

**3.2.3 AI-Human Alignment (1-2 paragraphs):** Convergence patterns, divergence patterns, what alignment reveals about blind spots or hidden opportunities.

**3.2.4 Cross-Category Synthesis (1-2 paragraphs):** Themes across categories, dependency/sequencing signals, overall strategic narrative.

**Robustness Matrix (required table):** Columns: Idea Title (top 8-10), Status (✓ ROBUST / ? CONDITIONAL / ✗ VULNERABLE), Brief explanation.

## 4. WRITING GUIDELINES

**Clarity over sophistication.** No jargon without explanation. No marketing language. Every claim traceable to input data.

**Strategic voice.** Active voice. Lead with conclusions. State uncertainty explicitly rather than hedging.

**Audience calibration:** Decision-makers get conclusions first; technical readers get methodology rigor and confidence levels; platform evaluators get transparency about human-AI integration and limitations.

**Conventions:** Title case for Part headings, sentence case for sections. Spell out one-nine, numerals for 10+, always numerals for scores. Cite data naturally in text, not footnotes.

### Paragraph Formatting (CRITICAL)

**MANDATORY RULES:**
1. Every paragraph break MUST use literal `\\n\\n` (double backslash, two n's)
2. DO NOT use real line breaks inside JSON strings
3. DO NOT use single `\n`
4. ONLY `\\n\\n` separates paragraphs
5. If a section contains N paragraphs, it MUST contain exactly N-1 occurrences of `\\n\\n`

**Valid Example:**
```json
"fieldName": "First paragraph with complete sentences.\\n\\nSecond paragraph continuing the analysis."
```

**Invalid Examples:**
```json
"fieldName": "First paragraph.
Second paragraph."

"fieldName": "First paragraph. Second paragraph."

"fieldName": "First paragraph\n\nSecond paragraph"
```

Apply this to every string field that represents prose or multiple paragraphs (e.g. opening_paragraph, methodology_note, analysis, insights, sequencing_rationale, adaptation_triggers, overview, closing, and all other paragraph-level content in the JSON).

## 6. ERROR HANDLING

| Missing Data | Fallback |
|---|---|
| overall_score | Flag in footnote; use mean of criterion scores |
| converges_with empty | Skip Convergence subsection; note "No convergences identified" |
| Sparse divergence data | Derive from criterion score variance (high std. dev. = disagreement) |
| < 2 scenarios | Single subsection: "Scenario Testing and Robustness Verification" |
| No sequencing detail | Sequence by dependency analysis (independent ideas first) |
| No quick_wins | Derive from top_priorities: shortest timeframe + lowest resources |
| No knowledge_gaps | One-paragraph Part 5: "Key questions to monitor include [infer from divergences]" |
| Missing pool data | Generic: "Evaluated across X pools including [infer from domain]" |
| Missing logo | Placeholder: "[MULTIVERZ LOGO]" |
| 50+ ideas | Move Annex A to supplementary document |
| Time constraints | Priority order: Exec Brief → Part 2 → Part 4. Abbreviate Parts 1, 3, 5 |
